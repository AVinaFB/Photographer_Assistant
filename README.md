# Photographer_Assistant
Мордовина А.Н.(ИУК5-52Б)

Веб-сервис для формирования онлайн-портфолио фотографа и управления записью клиентов.

Назначение системы: 
1) Формирование и просмотр портфолио 
2) Запись клиентов 
3) Отправка готовых снимков через удобный интерфейс
4) Выбор понравившихся снимков

Цель создания системы: 
Обеспечить централизованное хранения портфолио, публикацию готовой галереи 
по уникальной ссылке для каждого клиента и автоматизировать запись клиентов
на фотосессии.

Описание объекта автоматизации:
Процесс формирования и публикации онлайн-портфолио фотографа, 
предоставления клиентам удаленного доступа к галерее с примерами работ, 
а также процесс онлайн-записи клиентов на услуги с учетом календаря 
занятости фотографа.

Требования к системе:
1) Требования по эргономике и технической эстетике
Интерфейс системы должен быть интуитивно понятным и визуально привлекательным, 
адаптированным для просмотра на различных устройствах (ПК, планшеты, смартфоны). 
Административная панель должна содержать понятные элементы управления для 
загрузки фотографий, управления расписанием и просмотра понравившихся фото.
